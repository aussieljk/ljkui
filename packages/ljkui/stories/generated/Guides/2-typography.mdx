# Typography

_The size and weight scales, and how ljkui inherits your fonts._

Components like `<Heading />` and `<Text />` and used to render titles and body copy respectively.
Both of them share the same size and weight props to enforce consistent typography in your app.

## Typography scale

The typography scale is a 10 step scale where each step has its corresponding font-size and line-height value.
There is no letter-spacing step — ljkui sets no tracking at all, so text keeps whatever your own stylesheet

## Font families

**ljkui ships no fonts and sets no `font-family`.** There is nothing to override and nothing to undo:
`<Text>`, `<Heading>`, `<Strong>`, `<Em>` and `<Quote>` all inherit from whatever ancestor your app styles,
so the components match the rest of your page out of the box. The one exception is `<Code>`, `<Kbd>` and
`<DateField>`, which use the generic `monospace` keyword — your OS's default mono, not a font ljkui picked.

Set your type where you set it for everything else:

```css
body {
  font-family: 'Inter', sans-serif;
}
```

Want a different face for one part of the library? Style the component's class, or wrap it:

```css
.fui-Heading {
  font-family: 'Adobe Text Pro', serif;
}
.fui-Code {
  font-family: 'Fira Code', monospace;
}
```

### Self hosted fonts

You can use self-hosted fonts by downloading font files and adding them to your project.
Then define the named font styles and weights by using `@font-face`.

```css
@font-face {
  font-family: 'Inter';
  src: url('./inter-light.woff2') format('woff2');
  font-weight: 300;
  font-style: normal;
}

@font-face {
  font-family: 'Inter';
  src: url('./inter-regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
}

@font-face {
  font-family: 'Inter';
  src: url('./inter-medium.woff2') format('woff2');
  font-weight: 500;
  font-style: normal;
}

@font-face {
  font-family: 'Inter';
  src: url('./inter-bold.woff2') format('woff2');
  font-weight: 700;
  font-style: normal;
}
```

Then apply it to your page, and ljkui follows:

```css
body {
  font-family: 'Inter', sans-serif;
}
```

### Custom fonts with `next/font`

To load fonts using [next/font](https://nextjs.org/docs/pages/building-your-application/optimizing/fonts),
you can specify a CSS variable name and assign it to the 'inter' font.
Then, you can use `inter.variable` to add the CSS variable to your HTML document.

```tsx
import { Inter } from 'next/font/google';

const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-inter',
});

export default function RootLayout({ children }) {
  return (
    <html lang="en" className={inter.variable}>
      <body>{children}</body>
    </html>
  );
}
```

Then, just use the CSS variable on your page:

```css
body {
  font-family: var(--font-inter), sans-serif;
}
```
