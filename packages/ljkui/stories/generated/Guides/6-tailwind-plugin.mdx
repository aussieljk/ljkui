# Tailwind plugin

_Map the ljkui tokens to Tailwind classes with the theme plugin._

If you want to use ljkui with Tailwind CSS, you can use the ljkui Tailwind plugin.
The plugin maps all of the FUI color tokens, font related tokens and screen breakpoints to Tailwind CSS classes.

## Usage

Add the `ljkuiThemePlugin` to `plugins` in your `tailwind.config.js` file.

```js
import { ljkuiThemePlugin } from 'ljkui/tailwind';

export default {
  darkMode: ['class'],
  content: [],
  theme: {
    extend: {},
  },
  plugins: [ljkuiThemePlugin()],
};
```

Then instead of importing `ljkui/styles.css` stylesheet in your JSX,
do it in your Tailwind `globals.css` file like this. Remember to use the `@config` directive to point to your `tailwind.config.js` file.

```css
@config "../tailwind.config.js";
@layer theme, base, ljkui, components, utilities;

@import 'tailwindcss/theme.css' layer(theme);
@import 'tailwindcss/preflight.css' layer(base);
@import 'tailwindcss/utilities.css' layer(utilities);
@import 'ljkui/styles.css' layer(ljkui);
```

Then you can use the ljkui tokens via Tailwind classes.

```tsx
<div className="text-1 leading-1 bg-gray-alpha-50 text-success-700">ljkui</div>
```
