# Getting Started

**Quick links:** [GitHub](https://github.com/aussieljk/ljkui) · [llms.txt](/llms.txt)

ljkui is a React design system with a themeable component library, SwiftUI-style layout
primitives, and pluggable icon sets, heavily based on [Radix Themes](https://www.radix-ui.com/).

The library is still a work in progress so you might expect some breaking changes. If you have any
questions or suggestions, feel free to open an issue on [GitHub](https://github.com/aussieljk/ljkui).

<img src={HeroImg} alt="Modern user interface in dark mode" />

## Installation

Install the package:

```bash
bun add ljkui
```

React 16.8+ (up to React 19) is supported as a peer dependency.

## Set up styles

Import the stylesheet once, at the root of your app:

```tsx
import 'ljkui/styles.css';
```

A lighter bundle without some optional component styles is also available as
`ljkui/styles.lite.css`.

## Wrap your app in `Theme`

All components must render inside a `Theme`, which provides the design tokens
(colors, radii, typography):

```tsx
import { Theme } from 'ljkui';

export default function App() {
  return (
    <html>
      <body>
        <Theme accentColor="blue" grayColor="gray" appearance="inherit">
          <MyApp />
        </Theme>
      </body>
    </html>
  );
}
```

- `appearance="inherit"` follows a `light`/`dark` class on a parent element (e.g. set by your
  theme switcher). You can also force `appearance="light"` or `appearance="dark"`.
- See **Guides → Theming** for accent colors, custom palettes, fonts, and more.

## Use components

```tsx
import { Button, Card, Text } from 'ljkui';

export function Example() {
  return (
    <Card size="2">
      <Text size="2">Ready to go.</Text>
      <Button variant="classic">Get started</Button>
    </Card>
  );
}
```
