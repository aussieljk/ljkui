ljkui is the `ljkui` design system — a themeable set of React components
built on [Base UI](https://base-ui.com). Every component is driven by a single `<Theme>`
that controls appearance (light/dark), accent color, and gray scale.

## Installation

```bash
bun add ljkui
```

## Setup

Import the stylesheet once at the root of your app, then wrap it in a `<Theme>`:

```tsx
import 'ljkui/styles.css';
import { Theme } from 'ljkui';

export function App({ children }: { children: React.ReactNode }) {
  return (
    <Theme accentColor="indigo" grayColor="zinc">
      {children}
    </Theme>
  );
}
```

### Fonts

Nothing to install. ljkui sets no `font-family`, so every component inherits the type you already use —
whatever you set on `body` (or via `next/font`, or your Tailwind theme) is what the components render in.

## Your first component

```tsx
import { Button } from 'ljkui';

<Button variant="classic" size="2">
  Get started
</Button>;
```
