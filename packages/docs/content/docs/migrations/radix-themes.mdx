---
title: From Radix Themes
description: Translate familiar theme and component concepts to ljkui.
---

ljkui's theme model and many component conventions are inspired by Radix Themes. Migration can therefore happen
component by component.

```diff
- import '@radix-ui/themes/styles.css';
- import { Button, Theme } from '@radix-ui/themes';
+ import 'ljkui/styles.css';
+ import { Button, Theme } from 'ljkui';
```

```tsx
<Theme appearance="dark" accentColor="violet" grayColor="slate">
  <Button variant="solid">Continue</Button>
</Theme>
```

## What remains familiar

- Numeric size scales
- Semantic variants and accent colors
- A single theme boundary
- Composable, accessible primitives

## What to review

- ljkui is built on Base UI rather than Radix Primitives.
- Polymorphic composition uses `render`.
- Icon sets are selected through adapters.
- Some component names and compound namespaces differ.

Use global search to jump directly to a component and compare its generated props with your current usage.
