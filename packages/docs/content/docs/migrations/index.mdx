## A safe migration sequence

1. Install ljkui and its stylesheet without deleting your current system.
2. Add `<Theme>` at the nearest shared application boundary.
3. Move low-risk primitives first: buttons, badges, typography, and layout.
4. Migrate composite controls one screen at a time.
5. Remove the old provider and styles only after the final screen moves.

Use the theme control in this site's navbar to test the same components across appearances and accent colors.
